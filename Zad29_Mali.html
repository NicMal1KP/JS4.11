1. W jaki sposób można określić właściwość danego obiektu (dwa sposoby wraz z przykładami)?

    Właściwość obiektu można określić, wpisując wartość do pola odpowiedzialnego za tę właściwość.

    Sposób 1 – zapis z użyciem kropki:
    auto.marka = "Opel Omega"; – przypisuje tekstową wartość właściwości marka.
    auto.rok = 1996; – przypisuje liczbową wartość właściwości rok.

    Sposób 2 – zapis z użyciem nawiasów kwadratowych:
    auto["cena"] = 25000; – przypisuje wartość właściwości cena.

  2. W jaki sposób można odwołać się do pól (właściwości) i metod?

    Do pola lub metody odwołujemy się, podając nazwę obiektu, kropkę i nazwę pola albo metody.
    console.log(samochod1.kolor); – wyświetla właściwość kolor obiektu samochod1.
    samochod1.jedz(); – wywołuje metodę jedz obiektu samochod1.

  3. Wymień cechy charakterystyczne konstruktora.

    Konstruktor jest wywoływany podczas tworzenia obiektu. Może przyjmować argumenty, które służą do ustawienia właściwości obiektu. W JavaScript funkcja konstruktora zwykle zaczyna się wielką literą. Obiekt tworzony na jej podstawie za pomocą operatora new jest zwracany automatycznie.

  4. Konstruowanie obiektu na podstawie przykładu: obiekt ma trzy pola oraz jedną metodę.

    Przykład obiektu osoba_1 z trzema polami oraz jedną metodą:

    var osoba_1 = {
    nazwisko: "Kowalski",
    imie: "Jan",
    zawod: "piekarz",
    wyswietl: function() {
        document.write(this.nazwisko + " " + this.imie);
    }
};

  5. Znaczenie słowa this. Jak oddzielamy pola oraz metody?

    Słowo this pozwala odwołać się do pola lub metody bieżącego obiektu, np. this.nazwisko. W obrębie definicji obiektu pola i metody oddzielamy przecinkami.

  6. Konstruktor w JS na podstawie przykładu wraz z opisem.

    W JavaScript można zdefiniować funkcję konstruktora. Jej parametry są przypisywane do właściwości obiektu za pomocą słowa this: 

    function Osoba(imie, nazwisko, zawod) {
    this.imie = imie;
    this.nazwisko = nazwisko;
    this.zawod = zawod;
}

    Funkcja Osoba opisuje właściwości obiektu. Można jej użyć do utworzenia obiektu: var osoba_1 = new Osoba("Jan", "Kowalski", "piekarz");

  7. Znaczenie słowa kluczowego New wraz z przykładem.

    Operator new tworzy nowy obiekt na podstawie funkcji konstruktora i uruchamia konstruktor dla tego obiektu.
    Przykład: var osoba_1 = new Osoba("Jan", "Kowalski", "piekarz");

  8. Znaczenie słowa kluczowego prototype wraz z przykładem i opisem (szczególnie ważny tekst pogrubiony).

    Właściwość prototype pozwala dodać metodę, z której mogą korzystać obiekty utworzone za pomocą danego konstruktora.

    Metoda dodana do prototype jest dostępna dla obiektów utworzonych przez dany konstruktor.

    Osoba.prototype.wyswietl = function() {
    document.write(this.nazwisko + " " + this.imie);
};

var osoba_1 = new Osoba("Jan", "Kowalski", "piekarz");
osoba_1.wyswietl();

    W tym przykładzie metoda wyswietl została dodana do Osoba.prototype. Dlatego obiekt osoba_1 może ją wywołać. Wewnątrz metody this odnosi się do obiektu, który ją uruchamia.
